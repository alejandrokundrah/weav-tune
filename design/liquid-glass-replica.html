What was decoded, and how it maps to CSS

The source is a Figma SVG export, so all text is outlined paths and all artwork is base64 PNG inside <image> + <pattern> tiles. I recovered the layout from the rect geometry, rebuilt the type as live HTML text, and lifted every bitmap into design/assets/. The three materials share one DOM — only the material tokens change.

#949494 on #121212 is 6.2:1 — the flat reference already clears WCAG AA for body text, unlike the earlier red-accented screen. Blue on dark is ~5.4:1. Liquid+ lifts muted labels to #b9cbd5 / #a7bac6 and adds a 1px dark text-shadow, so 10–12px labels stay legible over the animated aura without changing the reference material.

Three material states

Reference — opaque #212121 panels, no blur, no aura. Matches the exported SVG exactly.

Glass — translucent rgba(38,47,56,.68), blur(26px) saturate(165%), soft specular rim, ambient aura at 60%, and slightly lifted --muted/--hair text tokens.

Liquid+ — rgba(30,42,53,.42), blur(38px) saturate(200%), 1px prismatic rim via mask-composite, feTurbulence + feDisplacementMap refracting the sheen, curved-glass inner shadows on pill buttons, full 20-second drifting aura, and high-contrast secondary labels with a dark text-shadow.

All decorative motion is disabled under prefers-reduced-motion, matching docs/echo-motion.md.

Handoff

The material is a small token set (--blur, --panel, --bar, --sheen, --rim, --aura, --tint, --sat, --muted, --hair) plus one .glass class, so the same shell can ship flat, glassy or fully liquid from a single user setting. In the product it maps to Settings → Look and feel alongside the existing AMOLED-black and Apple-Music-inspired player options; Compose can express it with Modifier.blur + a translucent Brush and a RoundedCornerShape border, SwiftUI with .ultraThinMaterial plus a stroked overlay. The 20-second aura cycle and reduced-motion freeze already match docs/echo-motion.md.
